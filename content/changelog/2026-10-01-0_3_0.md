title = "#2: v0.3.0"
date = 2026-08-31
+++

- **[#206 — Installation and limitations docs](https://github.com/rust-glancer/rust-glancer/pull/206):** Added installation guidance for Zed, Neovim, and VS Code forks, and clarified how analysis of unsaved edits works.

- **[#207 — Workspace initialization compatibility](https://github.com/rust-glancer/rust-glancer/pull/207):** Fixed startup for editors that provide their project through the older `rootUri` or `rootPath` fields instead of workspace folders.

- **[#209 — Initialization follow-up](https://github.com/rust-glancer/rust-glancer/pull/209):** Simplified the workspace-root fallback introduced in #207 and added regression coverage.

- **[#211 — Code folding](https://github.com/rust-glancer/rust-glancer/pull/211):** Added syntax-aware folding for Rust code, comment blocks, and import groups, allowing editors to collapse these regions accurately.

- **[#212 — Test infrastructure cleanup](https://github.com/rust-glancer/rust-glancer/pull/212):** Consolidated fixtures and snapshots, reorganized cache tests, and removed obsolete APIs and testing utilities, reducing maintenance overhead.

- **[#213 — Analysis and indexing architecture](https://github.com/rust-glancer/rust-glancer/pull/213):** Centralized analysis of unsaved bodies, standardized query cancellation, and unified body construction across indexing and on-demand analysis. This lets bodies built on demand work alongside deferred indexing.

- **[#214 — Richer documentation support](https://github.com/rust-glancer/rust-glancer/pull/214):** Added Rust syntax highlighting inside doc comments and resolved rustdoc links in comments and hover documentation. Documentation links now support hover information and navigation to the referenced item.

- **[#215 — Benchmark infrastructure cleanup](https://github.com/rust-glancer/rust-glancer/pull/215):** Removed the slower Gungraun/Callgrind benchmark infrastructure, with CodSpeed continuing to provide performance tracking.

- **[#216 — Faster CI](https://github.com/rust-glancer/rust-glancer/pull/216):** Improved caching and reused server builds across CI jobs, avoiding repeated compilation. Also canceled superseded PR runs and reduced Renovate churn.

- **[#217 — LSP dependency modernization](https://github.com/rust-glancer/rust-glancer/pull/217):** Updated `tower-lsp-server` and migrated protocol types to `gen-lsp-types`, temporarily using a fork for a required upstream fix.

- **[#219 — Internal simplification](https://github.com/rust-glancer/rust-glancer/pull/219):** Reorganized the body, type, semantic, and project layers around clearer responsibilities, consolidated span representations, and reduced duplicated syntax traversal.

- **[#220 — Return to upstream LSP server](https://github.com/rust-glancer/rust-glancer/pull/220):** Switched back to the official `tower-lsp-server` dependency after the required fix landed upstream.

- **[#221 — Naming consistency](https://github.com/rust-glancer/rust-glancer/pull/221):** Made the README consistently capitalize the project name as “Rust Glancer.”

- **[#223 — Optimized distribution builds](https://github.com/rust-glancer/rust-glancer/pull/223):** Added a dedicated distribution profile with full link-time optimization and a single codegen unit, enabling stronger optimization across crate boundaries for published binaries.

- **[#224 — Lower idle memory after indexing](https://github.com/rust-glancer/rust-glancer/pull/224):** Improved reallocation of retained metadata and explicitly forced mimalloc collection after indexing, allowing more fragmented memory to be returned before the server goes idle.

- **[#225 — Faster type inference](https://github.com/rust-glancer/rust-glancer/pull/225):** Replaced repeated whole-body inference passes with recursive inference, reducing redundant work and simplifying the implementation. Also fixed startup status reporting so clients reliably know when background indexing has finished.

- **[#226 — Stronger code quality tooling](https://github.com/rust-glancer/rust-glancer/pull/226):** Introduced project-specific Dylint checks and stricter Clippy and formatting rules, then applied them throughout the codebase.

- **[#227 — Updated rust-analyzer components](https://github.com/rust-glancer/rust-glancer/pull/227):** Refreshed the vendored rust-analyzer components, lexer dependencies, and generated syntax code, incorporating newer upstream parsing and macro infrastructure.

- **[#229 — New trait solver](https://github.com/rust-glancer/rust-glancer/pull/229):** Replaced Chalk and much of the custom inference machinery with Rust’s next-generation trait solver and compiler-compatible working types. This improved generic and associated-type inference while reducing duplicated logic.

- **[#230 — Readable hover signatures](https://github.com/rust-glancer/rust-glancer/pull/230):** Added Rust-aware formatting for function and method signatures, wrapping long parameter lists and `where` clauses. Hover cards also preserve clear spacing between the item path and signature.

- **[#231 — Navigate directly to module files](https://github.com/rust-glancer/rust-glancer/pull/231):** Go to Definition on `mod foo;` now opens the module’s defining file, such as `foo.rs`.

- **[#232 — Reliable builtin macro types](https://github.com/rust-glancer/rust-glancer/pull/232):** Simplified type resolution for builtin macros such as `format_args!` and `option_env!` by identifying their result types through compiler language items, preventing local names from interfering.

- **[#234 — Standard derive support](https://github.com/rust-glancer/rust-glancer/pull/234):** Added analysis support for compiler-provided derives such as `Clone`, `Default`, `Debug`, and comparison traits, making derived methods and trait bounds available without executing procedural macros. Also corrected edition-specific preludes and improved trait matching around unresolved types.

- **[#236 — Navigate to the relevant trait implementation](https://github.com/rust-glancer/rust-glancer/pull/236):** Go to Implementation now follows the trait implementation matching the call’s receiver and arguments, fixing cases that previously jumped to the type definition.

- **[#237 — Correct types for value-producing breaks](https://github.com/rust-glancer/rust-glancer/pull/237):** Fixed inference for labeled blocks and loop expressions whose result comes from `break`, including routing labeled breaks to the correct enclosing construct.

- **[#239 — Proper inference for `?`, ranges, and indexing](https://github.com/rust-glancer/rust-glancer/pull/239):** Integrated these operations into type inference through their real language items and trait relationships, replacing special-case approximations. This improves inference for custom `Try` and indexing implementations, slicing, and range endpoints.

- **[#240 — Find all trait-method implementations](https://github.com/rust-glancer/rust-glancer/pull/240):** Fixed implementation searches on trait methods to return all relevant implementations rather than only the one selected for a particular call.
