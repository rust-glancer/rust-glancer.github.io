title = "#3: v0.4.0"
date = 2026-10-21
+++

- **[#243 — Updated installation guidance](https://github.com/rust-glancer/rust-glancer/pull/243):** Documented Mason and Scoop support, linked the merged Neovim configuration, and clarified how to install a newer server binary independently of editor integrations.

- **[#244 — Basic const evaluation](https://github.com/rust-glancer/rust-glancer/pull/244):** Added evaluation of simple integer arithmetic, shifts, and numeric literals during type inference. Unsupported expressions now remain unknown instead of producing misleading values.

- **[#246 — Stable inlay hints while typing](https://github.com/rust-glancer/rust-glancer/pull/246):** Retried inlay hint requests interrupted by edits, keeping existing hints visible until updated results arrive and eliminating flicker.

- **[#248 — Preserve references to unknown types](https://github.com/rust-glancer/rust-glancer/pull/248):** Kept reference structure when the referenced type is unresolved, improving inference and inlay hints for partially known code.

- **[#249 — Basic trait-object support](https://github.com/rust-glancer/rust-glancer/pull/249):** Added analysis support for `dyn Trait`, allowing method calls through trait objects to resolve.

- **[#250 — Correct closure return types](https://github.com/rust-glancer/rust-glancer/pull/250):** Fixed explicit `return` expressions inside closures to use the closure's return type rather than the enclosing function's type.

- **[#252 — Auto traits and negative impls](https://github.com/rust-glancer/rust-glancer/pull/252):** Added basic support for auto traits such as `Send` and `Sync`, negative impls, and trait objects such as `dyn Foo + Send`. This also improves resolution of methods such as `anyhow::Context::context` that require auto-trait bounds.

- **[#253 — Faster item lookup setup](https://github.com/rust-glancer/rust-glancer/pull/253):** Reduced repeated item-lookup setup during reference searches by reusing information saved during indexing.

- **[#254 — Faster reference searches](https://github.com/rust-glancer/rust-glancer/pull/254):** Stopped following aliases during Find All References, substantially reducing the amount of code that needs resolving and bringing search behavior closer to rust-analyzer.

- **[#259 — More precise implementation locations](https://github.com/rust-glancer/rust-glancer/pull/259):** Go to Implementation and document symbols now select the type in an `impl` header instead of highlighting the entire block.

- **[#260 — More useful inlay hints](https://github.com/rust-glancer/rust-glancer/pull/260):** Added hints for inferred closure parameters and closure signatures, filtered obvious hints, and hid default generic arguments. Nested and iterator types now use compact labels with the full type available in a tooltip.

- **[#262 — Tuple and slice pattern inference](https://github.com/rust-glancer/rust-glancer/pull/262):** Added implicit reference matching for tuple and slice patterns, preserving the correct binding types when destructuring borrowed values.

- **[#263 — Associated types in signatures and parameters](https://github.com/rust-glancer/rust-glancer/pull/263):** Resolved `Self`-based associated types in implementation signatures and normalized associated types before destructuring parameters, improving inference for their bindings.

- **[#264 — Const and static values in hover](https://github.com/rust-glancer/rust-glancer/pull/264):** Extended const evaluation to declared constants and statics. Hover cards now show short initializers and include the evaluated value when available.

- **[#266 — Navigation inside declarative macros](https://github.com/rust-glancer/rust-glancer/pull/266):** Added hover and Go to Definition for macro arguments, including format string captures, and semantic highlighting for captured names.

- **[#267 — Consistent analysis for shared files](https://github.com/rust-glancer/rust-glancer/pull/267):** Files included by multiple Cargo targets now use a single target's analysis context, avoiding inconsistent merged results and redundant work.
