### Incremental analysis and unsaved edits

- **Moved analysis to Ajika.** Startup indexes declarations. Function bodies, const and static initializers, and most associated items are analyzed on demand. The disk cache can reuse unchanged results across edits and restarts. ([#295](https://github.com/rust-glancer/rust-glancer/pull/295), [#296](https://github.com/rust-glancer/rust-glancer/pull/296), [#297](https://github.com/rust-glancer/rust-glancer/pull/297), [#298](https://github.com/rust-glancer/rust-glancer/pull/298), [#300](https://github.com/rust-glancer/rust-glancer/pull/300), [#301](https://github.com/rust-glancer/rust-glancer/pull/301), [#303](https://github.com/rust-glancer/rust-glancer/pull/303), [#305](https://github.com/rust-glancer/rust-glancer/pull/305))
- Unsaved changes now take effect across open files. Completion can see a method added in another unsaved buffer, and Go to Definition uses the destination’s edited location. ([#306](https://github.com/rust-glancer/rust-glancer/pull/306), [#308](https://github.com/rust-glancer/rust-glancer/pull/308))
- Removed the package residency, indexing performance preference, and package batch size settings. ([#276](https://github.com/rust-glancer/rust-glancer/pull/276), [#291](https://github.com/rust-glancer/rust-glancer/pull/291))

### Completion and signature help

- **Auto-imports are back.** Completion can suggest out-of-scope items and methods from applicable extension traits, then add the `use` when selected. Suggestions respect `#[doc(hidden)]` across crates and can use documented re-exports. Zed displays the import path alongside the suggestion. ([#313](https://github.com/rust-glancer/rust-glancer/pull/313), [#319](https://github.com/rust-glancer/rust-glancer/pull/319))
- Completion ranks candidates by expected type, including at generic call sites. It also prioritizes relevant constructors, enum variants, and values whose names match the active parameter. ([#319](https://github.com/rust-glancer/rust-glancer/pull/319))
- Added signature help with the active parameter for functions, methods, closures, function pointers, and tuple constructors. ([#317](https://github.com/rust-glancer/rust-glancer/pull/317))

### Declarative macros

- Reworked macro expansion and name resolution. Rust Glancer analyzes macro-generated bodies and follows forwarded or repeated arguments back to the written source. This improves hover, navigation, references, completion, and inlay hints through expansions. ([#281](https://github.com/rust-glancer/rust-glancer/pull/281), [#283](https://github.com/rust-glancer/rust-glancer/pull/283), [#321](https://github.com/rust-glancer/rust-glancer/pull/321))
- Macro references follow aliases. Rename handles forwarded arguments when their copies agree, and format-string captures follow Rust edition rules. ([#299](https://github.com/rust-glancer/rust-glancer/pull/299), [#321](https://github.com/rust-glancer/rust-glancer/pull/321))

### Type inference and responsiveness

- Improved inference for async functions, blocks, closures, and `.await`, as well as callable values, tuple constructors, and argument coercions through `Deref` and `DerefMut`. ([#312](https://github.com/rust-glancer/rust-glancer/pull/312), [#315](https://github.com/rust-glancer/rust-glancer/pull/315), [#318](https://github.com/rust-glancer/rust-glancer/pull/318))
- Improved inference for struct update syntax, tuple patterns with `..`, imported enum variant aliases, and boolean conditions. Hover shows instantiated generic types, and parameter hints cover raw identifiers, `mut` bindings, and Unicode names. ([#314](https://github.com/rust-glancer/rust-glancer/pull/314))
- Reduced work for reference searches, rustdoc links in hover, trait lookup, and ranged inlay hints. Fixed a stack overflow during trait selection for cyclic `dyn Trait` candidates. ([#287](https://github.com/rust-glancer/rust-glancer/pull/287), [#308](https://github.com/rust-glancer/rust-glancer/pull/308), [#309](https://github.com/rust-glancer/rust-glancer/pull/309), [#310](https://github.com/rust-glancer/rust-glancer/pull/310), [#321](https://github.com/rust-glancer/rust-glancer/pull/321))

### Cargo, installation, and tooling

- Opening a workspace member or its `src/` directory now finds and watches the enclosing Cargo workspace. On Linux, the watcher skips symlinked directories to avoid wasting inotify watches. ([#272](https://github.com/rust-glancer/rust-glancer/pull/272), [#284](https://github.com/rust-glancer/rust-glancer/pull/284))
- Build-script output discovery supports Cargo 1.100’s build directory layout, including build directories outside the workspace. ([#311](https://github.com/rust-glancer/rust-glancer/pull/311))
- Server archives and VSIX packages now use stable filenames such as `rust-glancer-<target>.tar.gz` and `rust-glancer-<platform>.vsix`. The version remains in the GitHub release tag. ([#316](https://github.com/rust-glancer/rust-glancer/pull/316))
- `compare-lsp` now runs editor workload benchmarks against rust-analyzer, with smoke and release suites. ([#320](https://github.com/rust-glancer/rust-glancer/pull/320))
